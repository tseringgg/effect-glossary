# Face-name key collisions

Generated by `src/build_collisions.py`. This is a permanent build artifact, regenerated whenever the snapshot is refreshed -- not a one-time check.

## Why this file exists

`card-data.json` is a JSON object keyed by lowercased **face** name. Object keys are unique, so when two different cards share a face name only one survives the export and the other is **absent with no marker of any kind**. The loser cannot be recovered from the snapshot alone, which is why this report is built by comparing against MTGJSON AtomicCards.

The comparison only considers face-name keys that **MTGJSON itself** covers with more than one distinct Scryfall oracle id, then asks which of those ids survived in the snapshot. Cards printed after the snapshot date cannot appear as false positives.

## Sources

- snapshot: `data/card-data.json`, Last-Modified 2026-04-20, 34,645 entries
- reference: MTGJSON AtomicCards v5.3.0+20260921, date 2026-09-21, 35,282 names, 36,078 distinct face-name keys

## Result

- **50** face-name keys are contested by 2+ oracle ids in MTGJSON
- **44** of those keys are present in the snapshot holding one id while at least one other id was dropped
- **80** distinct oracle ids are silently missing as a result
